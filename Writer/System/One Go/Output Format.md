# Output Format

*What goes in the carousel file, and what never does.*

---

The carousel file contains **the copy that goes on the slides. Nothing else.**

```
Slide 1
[the text on slide 1]

Slide 2
[the text on slide 2]

...
```

**Never in the file:** captions, design notes, presentation guides, font or colour direction, strategy headers, goal or angle metadata, scores, checklists, revision logs, or format labels.

All strategy, scoring and reasoning is presented **in chat**, never written into the file.

Save to `Clients/[name]/Written Carousels/[name].md`.
