# Swipe File

Carousels by other people that worked. Not any one client's — these teach craft, so they live in Reference and every client's work draws on them.

**What goes here:** raw slide copy, exactly as written, one file per post. Nothing paraphrased, nothing tidied.

**What comes out:** [[Carousel DNA]], the cumulative read across every post in this folder. **Read that first** — the individual files are for checking a specific move.

**The one hard rule, carried from [[System/Learning the Client/Successful Post DNA|Successful Post DNA]]:**

> **Never turn a breakdown into a template.** If the output could be applied mechanically to any topic, it is wrong and gets deleted. What is being learned is *why this line came after that line*.
