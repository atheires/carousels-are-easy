## Notes

**This post breaks "hide every how" completely, and it is the most-liked post in the file so far.** All four prompts are printed in full. Nothing is withheld. 5,119 likes, 1,863 comments.

**Why the CTA still works:** the prompts are *images of text*. Reading them is easy; retyping four dense paragraphs from a screenshot is not. The friction the post monetises is not knowledge, it is **transcription**. The withheld thing isn't the information — it's the copy-paste. Worth holding against the system's law: what has to be withheld is *whatever makes acting on the post effortless*, and that is not always the knowledge itself.

**Giving the full prompt away is what proves the claim.** A vague "I built a memory system" invites doubt. A prompt with `decisions.md`, `people.md`, `preferences.md` named in it cannot be bluffed. **The specificity is simultaneously the proof and the value.** This is the claim-proof law taken to its limit — the proof *is* the whole deliverable.

**The cover does its argument in pictures.** Blocky robot → arrow → same robot in a hoodie with a face. "Make it feel human" is never explained in words on slide 1; it is shown. The headline states the outcome, the image states the transformation.

**Every slide has the identical scaffold:** bold two-line title, handwritten "Send Claude this message", arrow, code box. Fourth repetition of the same finding — **when the payload is a list of parallel things, layout repetition helps.** The reader learns the frame once on slide 2 and then reads only the content.

**Syntax highlighting inside the prompts is doing persuasion work.** The key phrases are coloured — `persistent memory system`, `read all of these files`, `generate 3 priorities for today`. It makes prose look like code, which makes it look like it will work, and it lets a skimmer get the gist of a dense paragraph in one pass.

**The caption pre-lists the four prompts with arrows** before the reader swipes. It tells them exactly what the four slides contain. That is the opposite of teasing, and it raises the swipe rate because the promise is concrete.

**"Want These Exact Prompts?"** — *exact* is the load-bearing word. The reader has just seen them and knows they are real. The ask is not for information, it is for a shortcut to information already proven to exist.
