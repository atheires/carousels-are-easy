# Branding extraction guide

Automatically extract the approved cover, generated here or provided by the user. Do not request another upload of an available image.

Save `Carousels/[name]/Branding.md` with:
1. Source image, approval status, selected saved brand/reference if any.
2. Colors: backgrounds, typography, accents, containers and usage rules.
3. Font roles: character, weight, case, scale ratios and emphasis. Avoid unsupported exact font identification.
4. Canvas/framing: 3:4 default, margins, safe zones, alignment and spacing.
5. Visual language: build method, motifs, materials, textures, lighting and density.
6. Identity: logo/handle presence if approved; none by default.
7. Body adaptations and explicit distinctions from cover-only rules.
8. Any applicable account profile, including required copy shapes, realism rules,
   character treatment and scene variation.

The actual approved cover anchors this post. Saved brands are starting material, not a substitute for inspecting the new cover. Supplied body references can clarify body treatment. If absent, derive coherent body designs without asking.


Immediately proceed to full body/closing generation. Refresh `Branding library.md` after production, accurately identifying whether local images exist and whether the full set was user-approved.
