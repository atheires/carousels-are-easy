# Body slide generation guide

Follow `Master workflow.md`. Cover approval triggers generation of all remaining slides, including the closing slide, without per-slide pauses.

Read current `Copy.md`, `Branding.md`, and `Memory/Body slides feedback log.md` with its supersession notice. Use supplied body references; absence means derive layouts from the approved cover, without asking.


Prepare the whole set internally: each slide's role, exact copy, alignment, hierarchy, palette, safe margins, image concept and reference paths. Lock positions, headline sizes and labels for repeated steps. Vary layouts deliberately for narrative, examples and closing slides. Preserve wording and slide order; rendering source-format markers is not required, but actual punctuation and bracketed placeholders are.


Use one image request per slide and parallelize independent requests where supported. Use stable approved local reference images, not a shifting selection of recent concurrent outputs. Inspect each result, keep correct slide-to-file mapping, and retry only failed or defective images.

Keep every word readable. Do not silently shorten text, add copy or change slide count. If a faithful readable layout is impossible, surface the specific conflict. Save numbered PNGs in the current carousel folder and preserve prior revisions.

After verifying the entire set, package and deliver via `Master workflow.md`. Record permanent user feedback. Show build instructions only if requested.
