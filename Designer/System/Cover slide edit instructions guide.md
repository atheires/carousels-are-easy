# Cover slide generation guide

Filename retained for compatibility. Follow `Master workflow.md`: generate the finished cover directly.

Read current `Copy.md` and `Memory/Cover slide feedback log.md` with its supersession notice. Inspect supplied references or the selected workspace brand. If neither exists, use `Branding library.md` selection. Do not search external collections.

Read `Design principles reference.md` and use the separate critic in `Design critic agent.md` for both BEFORE DESIGN guidance and actual-image review/recheck. Never use a two-line cover headline or exactly two visible text lines in the complete cover. Use one line or at least three meaningful lines, retaining exact approved copy and readable scale. No filler or workaround labels.

Internally specify what to keep/change/add/avoid; exact text; 3:4 canvas; safe margins; line-by-line alignment; type roles and sizes; object dimensions and clear gaps; palette, texture, lighting and visual metaphor. Borrow compatible reference qualities while deriving the subject from the new copy. Keep instructions in working notes rather than showing them by default.

Generate with the available image tool and imagegen skill, including final typography. Older mandatory manual-type separation is superseded. Inspect the render and fix text errors, spacing, contrast, and concept problems before presenting it. Apply compatible cheatsheet principles without forcing clutter into restrained styles.

Save versioned candidates immediately in `Drafts/`, repair required critic defects and recheck the actual revised image. Only show a critic-passed candidate for user cover approval. Critic approval is not user approval. Revise directly from user feedback, preserving prior versions and reviewing again. On user approval, save the selected cover as `Slide 1.png`, extract branding and automatically generate every remaining slide with the same pre-design and actual-image critic checks. No re-upload, body-reference question, or further go-ahead is required.
