

Source: the "How I Built a Money-Making Product Using Vibe Coding" carousel (Feedough).
Deconstructed 2026-07-23 from the cover plus three body slides.

---

## 1. Build method

**Pure hand-drawn: marker typography + black line-art illustration on flat white.** No
photography, no 3D, no vector polish, no texture. Every slide is the same two ingredients —
a rounded felt-tip typeface and a wobbly-but-confident pen drawing.

The only exception is a real UI screenshot on the product slide, and it is deliberately
tamed by wrapping it in a hand-drawn frame so it joins the sketch world instead of breaking it.

**Generated vs manual:** the illustrations are drawn/generated with no text; every word,
including the little labels sitting on drawn objects, is set manually afterwards. This split
is non-negotiable — baked text always drifts the font.

**Effort:** low per slide, but the illustrations must be *conceptually* designed, not
decorative. That's where the work is.

## 2. Cover construction

Centred stack, top ~48% of the frame:

| Slot | Spec |
|---|---|
| Headline L1 | Marker, black, centred, base size |
| Headline L2 | Marker, **blue**, centred, largest line — the promise |
| Headline L3 | Marker, black, centred, base size |
| Parenthetical | Marker, small (~0.3×), centred, contains a blue payoff phrase |
| Illustration | Lower ~45%, one wide scene, the black blob operating a machine |

Line spacing is tight (~0.9) so the headline reads as one object. Hook device: a concrete
outcome, with the blue landing on the part that creates desire.

## 3. Body slide format — three repeating layouts

There is no single body template; there are **three**, reused in rotation. Every one of them
still opens with a marker headline and closes with an illustrated machine.

**Layout A — Statement** *(the "My simple rule:" slide)*
```
headline top-LEFT (one line, black, ends in a colon)
  → left-aligned text block, 4–5 short lines, blue on the key phrase in each
  → wide illustration filling the bottom ~55%, objects labelled in blue
```

**Layout B — Question and flow** *(the "How do I make money from it?" slide)*
```
centred headline (a question)
  → one centred one-word beat under it ("Simple.")
  → illustration in the upper-middle
  → centred vertical flow: 4 short lines separated by small hand-drawn ↓ arrows,
    blue on the noun that carries each step
```

**Layout C — Exhibit** *(the "This is the product" slide)*
```
headline top-LEFT with one blue word inside it
  → 1–2 lines of left-aligned setup text
  → framed exhibit centred (screenshot in a hand-drawn rounded rectangle, corner ticks)
  → 1–2 centred closing lines, ending on a blue payoff
```

Mandatory in all three: marker font throughout, flat white, labelled illustration, generous
margins, one idea per slide.

## 4. Visual treatment of the body

Same build method as the cover — no downshift, which is unusual and is why the set feels
seamless.

**The illustration grammar is the standout idea: everything is a left-to-right machine.**
Objects sit on tables or connect through drawn pipes, cables, cranks, valves and levers, so
the eye physically travels an input → process → output path. Money lands in a labelled jar
at the end. The black blob is always the operator, never a bystander.

**Labels are the teaching mechanism.** Small blue marker words sit on plaques, box faces,
signs and jars, naming each part of the machine. The drawing isn't illustrating the text —
it's a diagram wearing a cartoon costume, and it repeats the text's structure spatially.

---

## 5. Type system

One typeface only: a rounded hand-drawn marker/felt-tip face with irregular baselines.
No second font anywhere in the deck.

| Role | Treatment |
|---|---|
| Cover headline | Large, centred, three lines, middle line blue and biggest |
| Body headline | ~0.75× cover, left-aligned (centred only for questions) |
| Body copy | ~0.45× the body headline, left-aligned, generous line spacing |
| Flow steps | Same as body copy, centred, separated by drawn ↓ arrows |
| Object labels | Small, blue, sitting inside the drawing |

Emphasis is **colour, not weight** — blue replaces bold. Never both.

---

## 6. Colour + texture

- Field: flat near-white (~#FCFCFC). Zero texture, zero grain, zero shadow.
- Ink: near-black marker.
- Accent: one strong blue (~#1B4DE4), used *sparingly on the cover* (one line) and
  *freely inline on body slides* (3–5 concept words per slide).
- Motion: orange-red ticks (~#F2542D), two or three tiny strokes, **only** in illustrations,
  never near type.

That cover/body difference in blue density is the subtlest and most important finding here.

---

## 7. Continuity mechanics

1. **The recurring character.** The solid-black blob with white dot eyes appears on every
   slide, always operating whatever the slide is about. This is the strongest binder in the
   style and does more work than any layout rule.
2. **The machine metaphor**, repeated with different apparatus each time.
3. **Blue as the concept colour**, consistent slide to slide.
4. **Flat white everywhere**, never broken.
5. **One typeface**, never broken.
6. **The payoff jar** — a labelled container the process empties into, recurring across slides.

---

## 8. Reproduction kit

**Illustration prompt skeleton**
> Simple hand-drawn black ink line illustration on plain white, thin even confident linework,
> slightly wobbly cartoon style, no shading, no colour. A solid black blob character with two
> white dot eyes and thin stick limbs [ACTION], connected by drawn [pipes/cables/levers] to
> [OBJECTS] arranged left to right. Blank plaques and sign faces left empty. Two or three
> tiny motion ticks near moving parts. **No text anywhere in the image.** 3:4.

**Manual type spec (never generated)**
Marker font throughout; body headline left-aligned top; copy block beneath; blue on the
concept word in each line; small blue labels placed onto the drawing's blank plaques; flow
arrows drawn between centred steps where the layout calls for it.

**Per-slide checklist**
- [ ] Flat white, no texture
- [ ] Marker font only, one typeface
- [ ] Black blob present and operating the scene
- [ ] Every drawn object labelled in blue
- [ ] Blue on concepts, black on grammar, never both on one phrase
- [ ] Orange ticks only inside the drawing
- [ ] One of the three layouts, not a fourth
- [ ] 3:4, ~10% margins

**Failure modes**
- If the illustration stops being a *machine* and becomes a decorative doodle, the style
  collapses into generic clip art.
- If blue is used on the cover as densely as on body slides, the cover loses its punch.
- If the labels are baked into the generated image, the font drifts and the set breaks.
- If a second typeface appears anywhere, it's over.

---

## Weaknesses

Very few — this is a well-executed style. The one genuine limit is that it only suits
content with a **process or mechanism** to show. Abstract, emotional, or narrative copy has
nothing for the machine metaphor to grip, and the illustrations turn decorative fast. Plan
the copy around visible cause and effect or pick a different style.
