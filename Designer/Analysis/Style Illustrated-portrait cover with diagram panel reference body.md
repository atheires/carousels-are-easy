
## 1. Build method

**Cover: vector illustration + pure typography, on a paper-texture field.**
The Tesla portrait is a flat vector/cel illustration — hard clean outlines, flat fill
shapes, limited shading, no photographic grain on the figure itself. It is a traced/
illustrated portrait, NOT a photo and not a 3D render. Sat on an off-white field with a
faint dot/paper texture and a very soft light-grey circular halo behind the shoulders that
lifts the subject off the background without a hard container.

**Body: diagram panel + pure typography.** No illustration of the subject, no photography.
Each body slide is a light-grey rounded panel containing a **found/hand-drawn diagram**,
with flat type beneath it on the same off-white field.

**Generated vs manual:** the portrait is the only generated/illustrated asset. Every diagram
is a sourced or hand-drawn sketch. 100% of the type is set manually. Nothing has baked text
inside a generated image.

**Why it works cheap:** only ONE bespoke asset (the portrait) had to be made. The other
8 slides are type + a panel + an existing diagram. This is a very high output-per-effort
style — worth noting if we want volume.

## 2. Cover construction

Lockup, top to bottom:

| Slot | Content | Spec |
|---|---|---|
| Punch line 1 | "Master Problem Solving" | High-contrast display serif (Didone/Playfair class), mixed weight — "Master" and "Solving" heavier/larger, "Problem" set lighter and slightly smaller between them. Near-full width, centred. |
| Sub-promise | "7 MENTAL MODELS TO MAKE BETTER DECISIONS" | Small grotesque sans, ALL CAPS, wide letterspacing, centred, ~0.15× the punch line. |
| Hero | Tesla portrait | Occupies the middle ~60% of the frame, centred, cropped at chest. |
| Callout | dashed curved arrow → "Nikola Tesla" / "Inventor of Alternating Current (AC) Power Systems" | Serif name, italic serif descriptor beneath. Lower-LEFT, arrow curving up-right into the face. |
| Swipe cue | "Swipe" + dark rounded square | Right edge, mid-height. Serif word, quiet. |
| Attribution | "Written by / Elevated Path" | Bottom-left, small italic serif + serif name. |

Scale ratios: punch ≈ 1.0 / sub-promise ≈ 0.15 / callout name ≈ 0.17 / attribution ≈ 0.10.

**Hook device:** number-promise ("7") + borrowed authority (a recognizable genius face).
Note the authority is *decorative* — Tesla is not one of the 7 models. That is deliberate:
the face buys the scroll-stop, the subtitle delivers the actual promise.

**The trick worth stealing:** the dashed-arrow-plus-label callout. It makes a static
portrait feel annotated and "educational" for almost no work, and it gives the cover a
second reading level.

## 3. Body slide format — the repeating slot structure

Every body slide (2–8) fills the same six slots in the same order:

```
1. VISUAL PANEL   — light-grey rounded rectangle, full width minus margins,
                    top ~35% of the slide, containing one diagram
2. INDEX TAG      — black rounded pill, small white bold sans: "#1 – By John Boyd"
                    Sits at the panel's BOTTOM-LEFT, straddling/overlapping the
                    panel edge so it visually stitches panel to text
3. TITLE          — heavy grotesque sans, black, large, left-aligned
4. DEFINITION     — one or two lines of serif body text, with the key phrase in
                    bold italic serif
5. HOW-TO BLOCK   — underlined bold serif label ("Steps:", "How to use it:") then a
                    bulleted or numbered list; each item leads with a bold-italic
                    term, then plain serif explanation
6. APPLICATION    — underlined bold serif label ("Useful For:") then one plain serif
                    sentence naming 3 real situations
```

Mandatory: 1, 3, 4, 5, 6. Optional: the "By [name]" half of the index tag (dropped on
#6 Occam's and #7 5x5 where there's no single attributable author — the pill shrinks to
just "#6").

What varies slide to slide: only the diagram, and whether the list is bulleted or numbered.
Everything else is locked. That rigidity is the whole point — it turns the post into a
reference card set people screenshot individually.

## 4. Visual treatment of the body

**The cover→body switch:** cover is illustrated + serif-display-led; body is
diagram-panel + heavy-sans-led. They are held together only by the shared off-white
paper field, the serif body voice, and the black/white restraint. This is a deliberate
downshift: the cover sells, the body informs.

**Diagram styles used (inconsistent — see weaknesses):**
- #1 OODA: hand-drawn marker cycle diagram, black on white
- #2 First Principles: hand-drawn zoom-chain (molecule → atom → nucleus → proton → quark) with a serif pull-quote under it
- #3 Six Hats: flat vector icon row, six coloured hats with labels beneath — the only saturated colour in the deck
- #4 80/20: simple two-pie vector chart, one blue fill
- #5 Root Cause: a low-res sourced fan/tree diagram in green Word-art type
- #6 Occam's: hand-drawn two-thought-bubble cartoon + serif pull-quote
- #7 5x5: a screenshot of a three-column table

Panel treatment is identical every time: soft grey fill, generous rounded corners, diagram
floated centrally with air around it, never bleeding to the panel edge.

## 5. Type system

| Role | Face | Treatment |
|---|---|---|
| Cover punch | High-contrast display serif | Mixed weights within one line, centred |
| Cover sub-promise | Grotesque sans | ALL CAPS, letterspaced, small |
| Body title | Heavy grotesque sans (Inter/Helvetica Black class) | Sentence case, left, large |
| Section labels | Bold serif | **Underlined** — this is the signature move |
| Body copy | Transitional serif (Georgia/Charter class) | Regular |
| List lead terms | Serif | **Bold italic** |
| Index pill | Bold sans | Small, white on black |

**Emphasis rule:** bold + italic + underline (on labels only). Colour is NEVER used for
emphasis in type — all type is black. Mixing serif body with sans titles is intentional
and consistent; don't "fix" it.

---

## 6. Colour + texture

- Field: off-white / bone (#F7F6F4 range) with a faint dot-screen paper texture, on every slide
- Panels: pale warm grey (#EFEFED range), no border, only rounded corners
- Type: pure black. No greys, no tints.
- Accent: none in the type. Colour appears ONLY inside diagrams, and only where the source
  diagram had it — the six hats, the blue pie, the green tree fan
- No shadows, no gradients, no gloss

So: functionally a **two-tone (black on bone) system where colour is quarantined inside
the panel.** Clean rule, easy to hold.

---

## 7. Continuity mechanics

1. **Identical panel geometry** at the top of every body slide — the strongest binder
2. **The numbered pill** (#1 → #7) — gives progress and countdown pressure
3. **Fixed off-white field** on all 9 slides
4. **Fixed label vocabulary** — "How to use it:" and "Useful For:" appear verbatim,
   underlined, on nearly every slide
5. **Fixed margin** (~7–8% side)
6. **Terminal slide breaks the pattern deliberately** — the CTA slide is empty except for
   centred text and a repost glyph. The sudden emptiness signals "it's over."

The cover shares only the field and the serif voice with the body — the portrait motif
never returns. Worth noting: this style does NOT use a recurring cast.

## 8. Reproduction kit

**Cover visual prompt skeleton**
> Flat vector illustrated portrait of [FIGURE], chest-up, three-quarter turn, clean hard
> outlines, flat fill shading, muted natural skin and clothing tones, on a plain off-white
> background with a soft light-grey circular halo behind the shoulders, subtle paper dot
> texture. No text anywhere in the image. 3:4.

**Body visual prompt skeleton**
> Hand-drawn black marker diagram of [CONCEPT] on plain white, sketch style, slightly
> irregular linework, handwritten uppercase labels, generous white space around the
> diagram, no colour. No decorative elements. 3:4 crop with the diagram centred.

**Manual type spec (never generated)**
- Cover: display serif punch line with internal weight variation, letterspaced sans caps
  sub-promise, dashed-arrow callout with serif name + italic descriptor, bottom-left
  attribution, right-edge swipe cue
- Body: black index pill overlapping panel bottom-left, heavy sans title, serif definition
  with bold-italic key phrase, underlined bold serif section labels, list with bold-italic
  lead terms, closing "Useful For:" line

**Per-slide consistency checklist**
- [ ] Panel top, same height, same corner radius, same grey
- [ ] Index pill present and overlapping the panel's bottom-left
- [ ] Title in heavy sans, everything else serif
- [ ] Both section labels underlined
- [ ] Zero colour outside the panel
- [ ] Same side margins

**Failure modes**
- If the diagrams aren't visibly hand-drawn or at least consistent in style, the deck
  reads as a scraped slop-post. Diagram consistency IS the quality signal here.
- If colour leaks into the type, the whole two-tone logic collapses.
- If the body list gets longer than ~5 items, the panel has to shrink and the layout breaks.

## Weaknesses in the original (do NOT copy these)

1. **Slide 2's list is scrambled** — reads "Orient / Decide / Orient / Act / Observe."
   Orient is duplicated, Observe is last. For a post about clear thinking, on the one model
   whose entire value is its sequence, this is a credibility hole. Correct: Observe →
   Orient → Decide → Act.
2. **Diagram style is inconsistent** — hand-drawn marker (#1, #2, #6) sits next to flat
   vector (#3, #4), a low-res green Word-art graphic (#5), and a raw screenshot (#7). The
   last two look lifted. If we run this style, all seven diagrams get drawn in ONE style.
3. **Slide 8's table repeats the same row twice** ("stressed over a client email" appears
   twice with an identical question and result). Nobody proofed it.
4. **Typo on slide 2** — "Conitnuous."
5. **Attribution is applied unevenly** — five models get a "By [name]" tag, two don't.
   Either commit or drop it.
6. **The cover's authority figure is a non-sequitur** — Tesla has no link to any of the
   seven models. It works as a scroll-stopper but a figure who actually authored one of
   the models (Boyd, de Bono, Pareto) would do the same job honestly.

**Verdict:** structurally excellent, executionally sloppy. The slot structure and the
panel/pill system are genuinely worth stealing. The diagram sourcing is not.
